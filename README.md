# Festival NFC Sidequest Generator

An interactive festival project combining handmade paracord kandi with embedded NFC technology. Tapping a phone against the bracelet triggers this web app to generate a random festival "sidequest"—encouraging community connection, hydration, dance-floor energy, and spontaneous fun across the grounds.

---

## 🎯 The Vision

Festivals are built on connection, shared energy, and spontaneous interactions. This project takes traditional kandi trading into the digital realm without requiring apps or account logins:

**Built with zero-dependency vanilla HTML/JavaScript so it runs immediately on any modern smartphone (iOS and Android) via a native NFC tap.
**Loaded with some side quests focused on safety, good vibes, stage exploration, and playful rave culture interactions.(ill try to remember to update them.
**Open & Adaptable: Designed to be easily cloned, modified, and reprogrammed onto any standard NFC chip (NTAG213, NTAG215, NTAG216).

---

## 🛠️ How It Works

1. **Hardware:** A micro NFC tag is woven directly into a custom paracord bracelet.
2. **Trigger:** Written via **NFC Tools** as a standard `URL / URI` record pointing directly to this hosted GitHub Pages site.
3. **Execution:** Scanning the bracelet opens the page and automatically pulls a randomized prompt from the quest array. A built-in "Reroll" button lets participants draw another challenge at any time.
